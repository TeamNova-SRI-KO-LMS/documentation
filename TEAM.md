# Team Roster

**Fill this in once.** Every document in this repository refers to the team
through placeholders of the form `[Student Name 1]`, `[Registration No. 1]` and
so on. `npm run fill-team` reads the table below and substitutes them
throughout, so the roster is recorded in exactly one place.

Until it is filled in, the placeholders remain visible — which is deliberate.
A cover page carrying `[Student Name 2]` is obviously incomplete; a cover page
carrying a plausible but wrong name is not.
